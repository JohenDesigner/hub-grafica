# Hub da Gráfica — Johen Arte Grafica

App de orçamento, pedidos, clientes e valores a receber, para usar no celular e no PC junto com o FpqSystem.

- Preços: lidos do site novo (`Johen-site/novo/dados/produtos.json`).
- Dados e login: Supabase (projeto `arbebltdznrmgnqchctw`, região São Paulo, plano grátis).
- Banco: `supabase/schema.sql` (já aplicado em 01/11/2026).
- Plano de construção: `docs/plano.md`.

## Se o banco pausar
O plano grátis pausa o projeto depois de 7 dias sem uso. Para reativar: supabase.com → projeto → botão **Restore project**. Os dados não se perdem.
